company's own marks, used on the company's own CRM — no third-party artwork.

was traced, recoloured or redrawn — these are the shipped files.

**Not used:** `bonanza-mobile.svg` from the same folder is a 181KB square app
icon in orange and cream (`#FF5B14`, `#FAD9AC`), which matches neither the
Bonanza wordmark's palette nor anything else in this product. If a square mark
is wanted for a favicon or an avatar, ask brand for the correct one rather than
using that.
